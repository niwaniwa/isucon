# Private ISU Python実装 パフォーマンス最適化

## 実施した最適化

### 1. データベースインデックスの追加
- 投稿の created_at でのソート用インデックス
- ユーザーIDによる投稿検索用インデックス 
- 投稿IDによるコメント検索用インデックス
- ユーザーIDによるコメント検索用インデックス
- 削除フラグでの絞り込み用インデックス
- 複合インデックス（効率的なクエリのため）

### 2. N+1問題の解決
- `make_posts`関数を最適化
- コメント数、コメント、ユーザー情報を一括取得
- 1投稿あたり3-4回のクエリから、全体で3-4回のクエリに削減

### 3. 画像配信の最適化
- 画像をファイルシステムに保存
- データベースからの画像取得を最小化
- `flask.send_file`を使用した効率的な配信

### 4. SQLクエリの修正
- 不正なWHERE句のないORDER BYクエリを修正
- LIMITを追加してデータ取得量を制限

### 5. アプリケーション起動時の最適化
- 初期化時にインデックスを自動作成
- 画像保存ディレクトリの自動作成

## セットアップ手順

1. 画像保存ディレクトリの作成:
```bash
./setup_images.sh
```

2. アプリケーション開始時に自動的にインデックスが作成されます

## 期待される効果

- **クエリ数**: 20投稿表示時に数百回 → 3-4回に削減
- **画像配信**: DBアクセス → ファイルシステムアクセスに最適化
- **検索速度**: インデックスにより10倍以上の高速化
- **メモリ使用量**: 不要なBLOBデータ転送を削減

# v2: 次世代パフォーマンス最適化計画

## 📋 v2改善計画概要

v1の基本的な最適化（N+1問題解決、インデックス追加、画像配信最適化）を踏まえ、**次世代の高性能化**を目指します。主要な改善は以下の5つの軸で行います：

## 🚀 主要改善項目

### 1. **フレームワーク刷新** (優先度: **High**)
- **Flask → FastAPI移行**: 3-5倍の速度向上
- **MySQLdb → aiomysql**: 非同期DB処理でスループット向上
- **Pydantic活用**: 高速JSONシリアライゼーション

### 2. **キャッシュ戦略導入** (優先度: **High**)  
- **Redis導入**: セッション、投稿一覧、ユーザー情報キャッシュ
- **アプリケーションレベルキャッシュ**: LRUキャッシュでメモリ内高速化
- **キャッシュヒット率80%以上**を目標

### 3. **配信機構刷新** (優先度: **Medium**)
- **Nginx最適化**: gzip圧縮、HTTP/2、静的ファイルキャッシュ
- **CDN検討**: 画像・静的ファイルの高速配信

### 4. **データベース最適化v2** (優先度: **Medium**)  
- **接続プール最適化**: 効率的なコネクション管理
- **クエリ最適化**: EXPLAIN ANALYZEベースの継続改善

### 5. **非同期処理導入** (優先度: **Medium**)
- **非同期エンドポイント**: 主要API の非同期化
- **バックグラウンドタスク**: 画像処理、統計更新

## 📦 v2セットアップ手順

### 1. 依存関係インストール
```bash
cd private_isu/webapp/python
uv sync
```

### 2. Docker環境構築
```bash
cd private_isu/webapp
docker-compose build
docker-compose up -d
```

### 3. v2アプリケーション起動
```bash
# Dockerfileは自動的にapp_v2.pyを起動
# または手動起動:
uvicorn app_v2:app --host 0.0.0.0 --port 8080 --workers 4
```

### 4. Nginx設定変更
```bash
# v2設定を有効化
sudo cp default_v2.conf /etc/nginx/conf.d/default.conf
sudo nginx -t && sudo systemctl reload nginx
```
