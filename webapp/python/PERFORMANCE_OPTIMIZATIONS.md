# Private ISU Python実装 パフォーマンス最適化

## 実施した最適化

### 1. データベースインデックスの追加
- 投稿の created_at でのソート用インデックス
- ユーザーIDによる投稿検索用インデックス 
- 投稿IDによるコメント検索用インデックス
- ユーザーIDによるコメント検索用インデックス
- 削除フラグでの絞り込み用インデックス
- 複合インデックス（効率的なクエリのため）

### 2. N+1問題の解決
- `make_posts`関数を最適化
- コメント数、コメント、ユーザー情報を一括取得
- 1投稿あたり3-4回のクエリから、全体で3-4回のクエリに削減

### 3. 画像配信の最適化
- 画像をファイルシステムに保存
- データベースからの画像取得を最小化
- `flask.send_file`を使用した効率的な配信

### 4. SQLクエリの修正
- 不正なWHERE句のないORDER BYクエリを修正
- LIMITを追加してデータ取得量を制限

### 5. アプリケーション起動時の最適化
- 初期化時にインデックスを自動作成
- 画像保存ディレクトリの自動作成

## セットアップ手順

1. 画像保存ディレクトリの作成:
```bash
./setup_images.sh
```

2. アプリケーション開始時に自動的にインデックスが作成されます

## 期待される効果

- **クエリ数**: 20投稿表示時に数百回 → 3-4回に削減
- **画像配信**: DBアクセス → ファイルシステムアクセスに最適化
- **検索速度**: インデックスにより10倍以上の高速化
- **メモリ使用量**: 不要なBLOBデータ転送を削減
